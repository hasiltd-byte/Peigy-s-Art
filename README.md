# בסטודיו עם פייגי — אמנות, סדנאות ויצירה אישית

אתר Next.js בעברית וב־RTL, עם עיצוב גלריה בגווני שמנת, זית וטרקוטה. כולל סיפור סטודיו, גלריה מסוננת והגדלת תמונות, סדנאות, תצוגת מסגרת מסתובבת ב־CSS 3D, קטלוג עם סל בקשות להצעת מחיר, פנייה בוואטסאפ, FAQ ועמודי פרטיות ונגישות.

## הפעלה

```sh
npm install
npm run dev
```

ב־PowerShell שבו הרצת סקריפטים חסומה השתמשו ב־`npm.cmd` במקום `npm`.

```sh
npm run typecheck
npm run build
npm run preview
```

`build` מייצר אתר סטטי בתיקיית `out/`. תצוגת ההפצה המקומית זמינה ב־http://127.0.0.1:3015. אפשר לשנות פורט עם משתנה הסביבה `PORT`. אין צורך בשרת Node באחסון סטטי.

## תוכן וצילומים

- הלוגו המקורי ותיאור הסטודיו נלקחו מעמוד הפייסבוק שסיפק המשתמש: https://www.facebook.com/FeigysStudio/ . שולבו קישורים לעמוד ולתהליכי היצירה שם.
- פייסבוק מציג את האלבומים והפוסטים מאחורי מסך התחברות בסביבת העבודה הזאת. לא ניתן היה לייבא מהם את תיק העבודות.
- כל הצילומים באתר הם צילומים אמיתיים; פרט ללוגו הם תמונות השראה מ־Unsplash, ומסומנים כך באתר. אין לייחס אותם לפייגי. מקורות מפורטים ב־`docs/PHOTO_SOURCES.md`.
- האיורים הישנים אינם מוצגים באתר. קובצי המקור נשמרו בתיקייה בלי למחוק אותם.
- את פרטי התמונות בגלריה ובחנות עורכים ב־`lib/art.ts`; את הצילומים עצמם מחליפים ב־`public/images/photos/`.
- זהו עדיין אתר הדגמה. פרטי הקשר נשמרו מהגרסה הקודמת; לא הומצאו מחירים, תאריכי סדנאות או המלצות. האינדוקס נותר חסום עד להשקה רשמית.

## החנות

החנות מאפשרת לבחור כיווני יצירה, לשנות כמויות, להסיר פריטים ולפתוח הודעה מסודרת בוואטסאפ לבירור מחיר וזמינות. ההודעה אינה נשלחת אוטומטית. אין סליקה, גבייה או הבטחת מלאי. כשיוזנו מוצרים, מחירים ותנאי אספקה מאומתים אפשר יהיה להרחיב להזמנות ותשלום מקוון.

## ביצועים ותנועה

האתר נבנה סטטית. לכל צילום WebP נוצרות שמונה רזולוציות בזמן הבנייה, והדפדפן מקבל את הגודל המתאים באמצעות srcset. שני גופני WOFF2 עבריים מוגשים מקומית; צילום הפתיחה והגופנים נטענים בעדיפות. תמונות ההמשך נטענות בעצלתיים ובעדיפות נמוכה. אין חיבור לפייסבוק בזמן טעינת האתר, הטמעות חברתיות, סרטוני רקע, ספריית אנימציות או ספריית WebGL. שרת התצוגה המקומי כולל gzip ומטמון; הגדרות מטמון ל־Vercel ולאחסון סטטי תואם שמורות ב־`vercel.json` וב־`public/_headers`.

תצוגת 360° היא הדמיית מסגרת עם צילום שטוח, ולא סריקת תלת־ממד של יצירה מקורית. אפשר לסובב בגרירה או באמצעות מחוון מקלדת. אנימציית המסגרת נעצרת מחוץ למסך. יש כפתור עצירה כללי, ותמיכה ב־`prefers-reduced-motion`.

## בדיקות דפדפן

`node scripts/qa-site.cjs` בודק גדלים 320–1440 פיקסלים, גלריה והחזרת פוקוס, סל בקשות, נוסח וואטסאפ, טופס פנייה, בקרי תצוגת 360°, תפריט נייד, תמונות, עוגנים ושגיאות JavaScript. נדרשים Playwright ו־Chrome מקומיים. אפשר להגדיר:

- `QA_PLAYWRIGHT_MODULE` — נתיב למודול Playwright אם אינו מותקן בפרויקט.
- `QA_CHROME_PATH` — נתיב לדפדפן Chrome.
- `QA_BASE_URL` — ברירת מחדל `http://localhost:3001/`; לבדיקת ההפצה `http://127.0.0.1:3015/`.

צילומי מסך נשמרים ב־`.qa/`, שאינה חלק מהקוד המנוהל.
