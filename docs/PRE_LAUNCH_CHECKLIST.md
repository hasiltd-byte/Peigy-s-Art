# רשימת בדיקה לפני הפיכת הדמו לאתר חי

- [ ] אישור בעלת העסק לפרסום תחת שמה, עם טלפון וכתובת.
- [ ] אימות מדויק של שם הרחוב/הכתובת בגוגל מפות.
- [ ] תמונות מקוריות ברישיון, לצד תיאורי תמונות מדויקים.
- [ ] הסבר מקצועי מאושר לגבי "טיפול באמנות" / הכשרות, או הסרה של ביטוי זה אם אין אישור מתאים.
- [ ] תוכן אודות אמיתי שאושר בכתב.
- [ ] מחירים, מועדים, מדיניות ביטול והתאמה למשתתפים — אם רוצים להציגם.
- [ ] הגדרת NEXT_PUBLIC_SITE_URL לדומיין הנכון.
- [ ] הסרת פס "אתר הדגמה" רק לאחר אישור.
- [ ] שינוי metadata.robots ל־index ושינוי robots.ts ל־allow רק לאחר אישור.
- [ ] הוספת אתר ל־Google Search Console והגשת sitemap.
- [ ] בדיקת WhatsApp במספר האמיתי ואישור נוסח ההודעות.
- [ ] בדיקת SEO: titles, description, canonical, og:image, schema, כותרות h1/h2.
- [ ] בדיקת נגישות אוטומטית (axe) ובדיקות ידניות במקלדת, NVDA, הגדלה, ניגודיות, מובייל.
- [ ] השלמת הצהרת נגישות + מדיניות פרטיות לפי מצב האתר בפועל והדין הרלוונטי.
- [ ] בדיקת Lighthouse/PageSpeed על כתובת פרוסה במובייל ובדסקטופ. 100 הוא יעד, לא הבטחה.
- [ ] בדיקת טופס, קישורים, ניווט, רספונסיביות ומפת האתר.
- [ ] תיעוד גרסת Next.js ושלמות התלויות, בדיקת עדכוני אבטחה לפי צורך.
