# פריסה ל־Vercel — מדריך קצר

**לחשבון מסחרי יש לבחור תוכנית שתנאיה מאפשרים שימוש מסחרי.**

1. פתחו את התיקייה `feigy-art-studio-nextjs` ב־VS Code, והתקינו `npm install`.
2. הריצו `npm run dev` וודאו שהאתר המקומי עובד.
3. שנו `NEXT_PUBLIC_SITE_URL` רק לאחר שבחרתם כתובת פריסה סופית.
4. מומלץ להעלות את הקוד למאגר Git פרטי ולהתחבר ל־Vercel. לא לשמור סודות במאגר.
5. צור פרויקט Vercel חדש, Framework: Next.js, Root: תיקיית הפרויקט.
6. הגדר Environment Variable בשם `NEXT_PUBLIC_SITE_URL` לכתובת שתהיה בפועל.
7. בצע Build: `npm run build`. מכיוון שהאתר מוגדר `output:'export'`, הוא מייצר אתר סטטי.
8. **זהו אתר הדגמה:** `noindex` ו־`robots.txt` חוסמים אינדוקס בכוונה. אין לפרסם תחת זהות העסק בלי אישור בעלת העסק.
9. כשהגרסה מוכנה, בדוק mobile / desktop, קישורים, WhatsApp, מקור התמונות ונגישות.

ניתן גם להעלות ישירות את תיקיית `out/` לאחסון סטטי עצמאי.
